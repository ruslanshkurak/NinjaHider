# NinjaHider 🥷

**NinjaHider** — это легковесная утилита для Windows, предназначенная для обеспечения максимальной приватности во время стриминга, записи экрана или совместной работы. Она позволяет мгновенно скрывать выбранные приложения из панели задач и делать их абсолютно невидимыми для программ захвата экрана (OBS, Discord, Zoom и др.).

## Основные возможности

*   **Taskbar Stealth:** Удаляет иконки приложений из панели задач без закрытия самих программ.
*   **Capture Protection:** Использует системную функцию `SetWindowDisplayAffinity`, чтобы сделать окно черным или прозрачным для захвата видео, при этом вы продолжаете видеть его на своем мониторе.
*   **Background Daemon:** Работает в виде невидимого фонового процесса, не мешая основной работе.
*   **Hotkey Control:** Мгновенное переключение режима защиты с помощью глобальных горячих клавиш.
*   **Dynamic Targets:** Легкое добавление новых программ для скрытия через файл `targets.txt` или консольную панель управления.

## Как это работает

Проект разделен на две части для обеспечения максимальной стабильности:
1.  **Daemon (Фоновый процесс):** Запускается без окна консоли, слушает горячие клавиши и применяет магию WinAPI к целевым окнам.
2.  **Control Panel (Панель управления):** Консольный интерфейс для настройки списка программ и управления состоянием защиты.

## Использование

1.  Запустите `StartNinja.bat` от имени Администратора.
2.  Добавьте нужные программы в список (например, `add discord.exe`).
3.  Используйте горячие клавиши:
    *   `Ctrl + Alt + H` — Включить/выключить скрытие программ.
    *   `Ctrl + Alt + C` — Скрыть/показать окно консоли управления (если оно мешает).

## Команды панели управления

*   `add <name>` — Добавить программу в список защиты.
*   `remove <name>` — Удалить программу из списка.
*   `list` — Показать текущий список целей.
*   `restore` — Принудительно вернуть все иконки в панель задач (в случае сбоя).
*   `stop` — Полностью завершить работу фонового процесса.
*   `exit` — Закрыть панель управления (защита продолжит работать в фоне).

## Технические детали

*   **Язык:** Python 3
*   **Библиотеки:** `ctypes` (WinAPI), `keyboard`.
*   **Технологии:** 
    *   Манипуляция стилями `WS_EX_TOOLWINDOW` и `WS_EX_APPWINDOW`.
    *   Внедрение DLL-пайлоада в целевые процессы для активации защиты от захвата.
    *   Использование `pythonw.exe` для безэкранной работы.
